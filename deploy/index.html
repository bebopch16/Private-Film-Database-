元数据校对

本页仅做智能识别与筛选，不做任何自动修改：点击条目进入对应编辑页，人工核对「英文片名 / 原文片名」后保存；修复后重新打开本页即可刷新。

历史版本

每次「恢复备份 / 导入 Excel / 从云端拉取」之前，当前数据都会自动留档到这里；回滚前也会把当前状态再留一份，所以误点也能退回来。保留规则：最近 20 份 + 近 7 天每天 1 份。数据只存在本机浏览器，不占项目体积。

剧照缓存迁移

换地址时（例如从 localhost:8080 改到发布网址）浏览器存储互不相通，剧照缓存也不会跟过去。 用它把「哪部影片对应哪张剧照 + 文字该用深色还是浅色」搬过去，新地址不必重新搜索 TMDb （api.themoviedb.org 在国内常被 DNS 污染，重搜可能失败）。
注意：这里只搬元数据；剧照图片本身会按需从 CDN 重新下载，所以文件很小。
建议顺序：① 先「备份」导出数据 → ② 在新地址「恢复」数据 → ③ 再回到本页导出剧照缓存、在新地址导入。因为剧照映射的键含片名，先恢复数据可避免改过片名的条目对不上。导入只影响本机浏览器缓存，不动任何数据。
